              Hands · your coding agents
              
        
              Say the task. Your agent does the coding.
              
        
              Claude Code, Codex, Antigravity, OpenCode, Gemini CLI and Aider run on this computer, signed in with your own accounts. FlowMesh never sees those accounts. It shows the exact command and folder, and runs the task once when you approve.
              
      
              

      
              
        
              Coding agents run on your computer. This hosted page cannot start a program, so it can only describe them. Open the desktop app (or run python bridge.py) to connect Claude Code, Codex, Antigravity, OpenCode, Gemini CLI or Aider.
              
      
              

      
              
        
              READ
              Plan or read-only mode. The agent studies the project and proposes changes. It edits nothing.
              
        
              WRITE
              Edit mode. Changes files inside the project folder you chose. Always shown and approved first.
              
        
              DANGER
              Skips the agent’s own safety checks. Needs a second, explicit confirmation every time.
